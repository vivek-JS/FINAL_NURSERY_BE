# 🚀 Quick Fix: Enable Text-to-Speech API

## ⚡ One-Click Solution

**Click this link to enable the API:**
👉 **https://console.developers.google.com/apis/api/texttospeech.googleapis.com/overview?project=815179027284**

---

## 📋 Steps (2 minutes)

1. **Click the link above** (opens Google Cloud Console)
2. **Click the blue "ENABLE" button**
3. **Wait 1-2 minutes** for activation
4. **Test again:**
   ```bash
   cd FINAL_NURSERY_BE
   node test-video-direct.js
   ```

---

## ✅ What You'll See After Enabling

When you test again, you should see:
```
✅ Audio generated (XX KB)
✅ Audio saved to: ...
✅ Audio duration: X.Xs
✅ Video created: ...
✅ Video Generated Successfully!
```

---

## 🎬 After Success

Once the test works:
1. **Restart your server** (if not already running)
2. **Open Ram Agri Sales Dashboard**
3. **Click "Video (Day)" or "Video (Week)" button**
4. **Video will generate and play!** 🎉

---

## ❓ Still Getting 403 Error?

If you still see 403 after enabling:
- **Wait 2-3 more minutes** (API activation can take time)
- **Check API is enabled:** https://console.cloud.google.com/apis/library/texttospeech.googleapis.com
- **Verify API key:** https://console.cloud.google.com/apis/credentials
- **Make sure you're in the correct project:** Project ID `815179027284`

---

**Enable the API, wait 2 minutes, then test!** 🚀
